## Smallest release blockers, ranked by user impact

1. **Accepted component arguments can silently produce wrong UI.** The grouped
   argument fixture expects 202 but renders NaN in the browser. The direct global
   argument fixture expects 200 but renders NaN; native gives 20. Before RC,
   browser argument binding must produce the authored result or reject unsupported
   forms before runnable assets, with original-source remediation. Merely labeling
   these accepted programs unsupported does not satisfy fail-closed acceptance.
2. **Release/distribution identity and licensing approval are unfinished.** CLI,
   C API and doctor report 0.1.0-dev; CMake/CPack declare 0.1.0; editor is 0.2.0.
   Agree the v0.3 artifact/version/extension-compatibility mapping and verify a
   clean install of those exact artifacts before any tag. The owner must approve
   Apache-2.0 rights/provenance and retained third-party notices. This PR prepares
   those materials; it cannot establish contribution ownership by Git authorship.
3. **Diagnostics do not yet support the advertised application workflow.** The
   unchanged Taskboard check exits 0, but lint exits 1: **346 errors / 7 warnings**
   (353 issues). Before claiming component/app lint support, resolve false binding
   diagnostics or provide an explicit, independently tested diagnostic support
   boundary. Do not weaken Taskboard, suppress errors or equate check with lint.
