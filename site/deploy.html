Deploy

Install RC.3, then publish static browser assets.

JTML compiles supported reactive apps to static browser assets. Its separate live development server is loopback-only trusted-code tooling; the public RC.3 packages are experimental, unsigned and unnotarized.

Download and verify

Published v0.3.0-rc.3 packages and SHA256SUMS. Download the bundle matching your platform. The -install tarball is an alternative CPack layout.

# Linux x86_64: beside the downloaded files
grep '  jtml-0.3.0-rc.3-linux-x86_64.tar.gz$' SHA256SUMS | sha256sum -c -
tar -xzf jtml-0.3.0-rc.3-linux-x86_64.tar.gz
# macOS arm64 instead:
grep '  jtml-0.3.0-rc.3-darwin-arm64.tar.gz$' SHA256SUMS | shasum -a 256 -c -
tar -xzf jtml-0.3.0-rc.3-darwin-arm64.tar.gz

Compile the Counter

cd release
./bin/jtml --version
# jtml 0.3.0-rc.3
./bin/jtml check examples/friendly_counter.jtml
./bin/jtml build examples/friendly_counter.jtml --target browser --out counter-dist
python3 -m http.server 8000 --bind 127.0.0.1 --directory counter-dist

Open localhost:8000; Add one changes 0 to 1 and Reset returns to 0. Keep all four generated assets together. Try the homepage Counter and inspect build provenance.

Platform contract

Ubuntu 22.04 x86_64; Apple Silicon macOS with minimum deployment target 14.0, tested physically on 14.4.1 and hosted on 15. Other distributions/versions are not independently certified. No Windows, Linux arm64, Intel/universal Mac, Python wheel or VSIX package is included.

Unsigned/unnotarized downloads may be subject to local OS policy. Matching header/library C API smoke tests do not establish a stable cross-version ABI.

Local Studio

./bin/jtml studio --port 8001

Studio, tutorial and live serve bind to loopback and execute trusted local code. They are not public production servers. Packaged resources are discovered relative to the executable.

Source builds

RC.3 includes both the component-input reset fix and clean browser production imports. For a complete form, use the first-app guide. Known general slot limitations still apply.

Build from source with a C++17 compiler and CMake. Source builds default to 0.3.0-dev; the published binaries report 0.3.0-rc.3. Optional Python bindings and VSIX publication have separate requirements.

Static hosting

The generated Counter needs no backend. Serve index.html, jtml-runtime.js, components/index.js and app.js together with HTML/JavaScript MIME types. Scripts use script-src 'self'; the example's inline styles require a separate style policy.
