Experimental language for web applications

JTML

Write HTML-shaped markup, observable state, actions, and components in Friendly JTML 2. The C++17 compiler generates HTML and JavaScript for supported browser-local applications. The v0.3.0-rc.3 experimental prerelease is available for technical testers; JTML is not production-ready.

Syntax

Shorter than HTML, still HTML-shaped.

JTML keeps tags, attributes, nesting, events, state, and derived values. Friendly JTML 2 removes closing-tag repetition, statement terminators, and framework ceremony.

Compiler direction

Readable source, compiler-owned behavior.

Friendly source flows through Expression IR, semantic analysis, and a Runtime Plan into browser code. Supported shapes use static component create and update paths. Dependency correctness and broader application coverage are still being validated.

Auditable Source

Readable .jtml files compile to regular HTML, and the CLI commands are scriptable in CI.

Install RC.3

Take Counter home with RC.3.

Download the matching archive and SHA256SUMS from the public v0.3.0-rc.3 prerelease. Ubuntu 22.04 x86_64 and macOS arm64 are tested; macOS 14.4.1 was exercised physically and macOS 15 on hosted runners. Other platforms remain unverified. The binaries are unsigned/unnotarized; read the installation and platform contract.

RC.3 includes the component-input reset and modular production import fixes. The embedded Counter above has its own compiler provenance.

Verify And Extract

# Example: macOS arm64 bundle
# Run beside the downloaded tarball and SHA256SUMS.
grep '  jtml-0.3.0-rc.3-darwin-arm64.tar.gz$' SHA256SUMS | shasum -a 256 -c -
tar -xzf jtml-0.3.0-rc.3-darwin-arm64.tar.gz
cd release

Check And Compile

./bin/jtml --version
./bin/jtml check examples/friendly_counter.jtml
./bin/jtml build examples/friendly_counter.jtml --target browser --out dist/counter

Experimental means bounded

What this release does not promise.

Five native-renderer discrepancies remain. Reference HTML exceeds its 70000-byte microfixture budget (99952 bytes); the shared runtime remains within 271961/272000 bytes. Type/source-span coverage and tooling are experimental.

RC.3 includes the component-input reset and modular production import fixes. General slots remain incomplete: conditional slots may lose content, slotted child components may not initialize, and caller-slot input setters may be absent. Direct root-loop components and root ID/select limitations remain documented. There is no stable cross-version C ABI, production-service contract, or Windows/Intel/universal Mac/Linux arm64/Python wheel/VSIX package.

Roadmap

Simple syntax first, reliable runtime next.

  1. Local authoring Studio, starter generator, syntax checker, tutorial, examples, and Friendly `jtml 2` syntax.
  2. Reliable reactivity Make `let`, `get`, arrays, dictionaries, stores, effects, fetches, and component instances predictable.
  3. HTML parity Boolean attributes, custom elements, SVG-friendly names, and void-element ergonomics.
  4. External technical testing RC.3 is published with checksums, provenance and physical macOS 14.4.1 acceptance. Collect small reproducible reports before expanding the support contract.
