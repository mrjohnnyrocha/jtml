Experimental language for web applications

JTML

Write HTML-shaped markup, observable state, actions, and components in Friendly JTML 2. The C++17 compiler generates HTML and JavaScript for supported browser-local applications. Active development targets an experimental v0.3 research preview; JTML is not production-ready.

Research preview CLI defaults to 0.1.0-dev; extension metadata is 0.2.0. v0.3 is the development target.

Syntax

Shorter than HTML, still HTML-shaped.

JTML keeps tags, attributes, nesting, events, state, and derived values. Friendly JTML 2 removes closing-tag repetition, statement terminators, and framework ceremony.

jtml 2 selects Friendly syntax page opens the app root click wires actions to events get keeps values reactive

Compiler direction

Readable source, compiler-owned behavior.

Friendly source flows through Expression IR, semantic analysis, and a Runtime Plan into browser code. Supported shapes use static component create and update paths. Dependency correctness and broader application coverage are still being validated.

Auditable Source

Readable .jtml files compile to regular HTML, and the CLI commands are scriptable in CI.

Local Studio

jtml demo opens Studio with Run, Lint, Fix, Format, Export HTML, diagnostics, compiler artifacts, autosaved drafts, versioned local Save/history, command palette, and live preview.

Two Deployment Modes

Build HTML and JavaScript for supported browser-local apps, or use the separate live backend for Studio and local development.

Verification Loop

Doctor checks toolkit shape; tests cover lexer, parser, friendly syntax, formatter, linter, and examples.

Try it locally

Build and run a local example.

Start with Git, a C++17 compiler, CMake (validated with 3.31.3), and Python 3 to serve static files. Dependency downloads require network access or a cache. No released v0.3 package is assumed.

1

Clone And Build

git clone https://github.com/mrjohnnyrocha/jtml.git
cd jtml
cmake -S . -B build -DJTML_BUILD_PYTHON=OFF
cmake --build build --target jtml_cli --parallel
2

Check And Compile

./build/jtml --version
./build/jtml check examples/friendly_counter.jtml
./build/jtml build examples/friendly_counter.jtml --target browser --out dist/counter
3

Open In Your Browser

python3 -m http.server 8000 --directory dist/counter

Open localhost:8000 and try Add one and Reset. Stop the server with Ctrl+C.

Roadmap

Simple syntax first, reliable runtime next.

  1. Local authoring Studio, starter generator, syntax checker, tutorial, examples, and Friendly `jtml 2` syntax.
  2. Reliable reactivity Make `let`, `get`, arrays, dictionaries, stores, effects, fetches, and component instances predictable.
  3. HTML parity Boolean attributes, custom elements, SVG-friendly names, and void-element ergonomics.
  4. Distribution validation Verify documentation, local artifacts, ownership, and security boundaries before release decisions.
